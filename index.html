Rclone Drive

This is a private-use OAuth client operated by one individual to connect that same individual's Linux computer to their own Google Drive using the open-source rclone application.

Purpose

The client lets rclone mount and synchronize the owner's Google Drive files on the owner's computer. It is not offered to the public and has no separate user accounts.

Google data access

The client requests Google Drive, Google Docs, and Drive metadata permissions solely so rclone can list, read, create, update, and synchronize files when instructed by the owner.

OAuth credentials and file data remain on the owner's devices. This site does not receive, collect, store, sell, or share Google user data.

Software

Rclone is an independent open-source project. See the official rclone Google Drive documentation.
