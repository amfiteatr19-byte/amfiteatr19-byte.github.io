Privacy Policy

Effective date: September 2, 2026

Rclone Drive is a private-use OAuth client operated by one individual to connect that individual's computer to their own Google Drive through the open-source rclone application.

Data accessed

The client may access Google Drive files, Google Docs content, and Drive file metadata only when the owner instructs rclone to mount, list, read, create, update, or synchronize files.

How data is used

Google user data is used only to provide the requested local file access and synchronization. It is not used for advertising, analytics, profiling, or any unrelated purpose.

Storage and sharing

OAuth credentials and any rclone cache remain on devices controlled by the owner. This website has no backend and does not receive or store Google user data. Google user data is not sold, transferred, or shared with third parties.

Retention and control

The owner controls local files and caches and may delete them at any time. Access can be revoked at any time from the owner's Google Account security settings.

Limited use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions may be submitted through the repository issue tracker.
